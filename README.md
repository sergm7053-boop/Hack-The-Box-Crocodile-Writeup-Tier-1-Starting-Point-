**Дата проведения аудита:** 12 октября 2026 г.
**Платформа атаки:** Kali Linux arm64 (Hypervisor: VMware Fusion Pro, Apple Silicon M4)
**Целевой хост (Target IP):** `10.129.1.15`
**Результат:** Успешный взлом облачной инфраструктуры через цепочку эксплуатации (Exploitation Chain), неавторизованный захват веб-панели администрирования, эксфильтрован Root-флаг.

## 1. Введение и Теоретический анализ уязвимостей
В ходе планового тестирования на проникновение исследована облачная инфраструктура `Crocodile`. Данный аудит демонстрирует классический вектор связывания мелких дефектов безопасности (Exploitation Chains) для получения первоначального доступа к закрытым системам.

### 1.1. Специфика цепочки эксплуатации
Атака базируется на компрометации двух независимых сетевых служб, развернутых в облачном контейнере:
1. **Незащищенное хранилище FTP (порт 21):**
Уязвимость некорректной конфигурации прав доступа (Security Misconfiguration).
2. **Веб-сервер Apache HTTPD (порт 80):**
Утечка критически важных данных и отсутствие надлежащей изоляции административных панелей бэкенда.

## 2. Этап разведки и сбора скрытых конфигураций (Enumeration)
### 2.1. Верификация зашифрованного канала
Перед запуском активных сканеров проведена проверка стабильности связи с облаком через `ping`:
```bash
ping -c 3 10.129.1.15
```
**Результат:** Пакеты доставлены без потерь (`0% packet loss`), зафиксирован стабильный отклик ~132-137 мс.
 
### 2.2. Веерное Black Box сканирование (Nmap)
Для первичного обнаружения активных сетевых портов и сбора версий ПО запущен веерный скан периметра хоста:
```bash
sudo nmap -sC -sV 10.129.1.15
```
**Лог сканирования Nmap:**

Анализ логов выявил открытый веб-сервер **Apache 2.4.41** и службу **vsftpd 3.0.3** со включенным анонимным доступом без авторизации (`Anonymous FTP login allowed`).

### 2.3. Эксфильтрация скрытых данных из FTP-хранилища
Используя дефект конфигурации, осуществлено беспарольное подключение к удаленному диску:

* `allowed.userlist.passwd` — Список соответствующих паролей.
 
После завершения сессии (`exit`).

## 3. Направленный веб-фаззинг и захват админки (Exploitation)
### 3.1. Картирование веб-структуры через GoBuster
При открытии целевого IP-адреса в браузере Firefox отображается стандартный шаблон бизнес-сайта, внешняя навигация на котором отсутствует. Для обнаружения скрытых административных панелей и изолированных скриптов бэкенда без предварительного анализа стека технологий принято решение запустить слепой веерный фаззинг директорий по стандартному хакерскому словарю. С учетом специфики современных веб-платформStarting Point, поиск выполнялся с жесткой фильтрацией расширений по маске **`-x php,html`**:
```bash
gobuster dir --url http://10.129.1 --wordlist /usr/share/wordlists/dirb/common.txt -x php,html
```
По результатам фаззинга установлено, что сайт функционирует на языке **PHP** (status 200).
**Лог сканирования GoBuster:**
```text

/login.php            (Status: 200) [Size: 1577]
/dashboard            (Status: 301) [Size: 314]
/logout.php           (Status: 302) [Size: 0] --> login.php
```
Сканер успешно идентифицировал изолированный бэкенд-скрипт **`/login.php`**.

## 4. Рекомендации по устранению уязвимостей (Remediation)
1. **Отключение анонимного FTP:**
В конфигурационном файле `/etc/vsftpd.conf` принудительно изменить директиву на `anonymous_enable=NO`, заблокировав беспарольный вход.
2. **Очистка публичных каталогов:**
Удалить любые списки учетных данных, временные бэкапы и конфигурационные вордлисты из системных папок общего доступа.
3. **Защита панели входа:**
Реализовать ограничение на количество попыток авторизации (Rate Limiting / Fail2ban) на странице `login.php` для блокировки брутфорса и закрыть доступ к админ-панели внешним пользователям с помощью сетевых правил.
